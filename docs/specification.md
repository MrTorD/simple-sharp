# Язык SimpleSharp

## О языке

SimpleSharp - строго типизированный императивный язык программирования.

Точкой входа в программу является функция `main`. Язык относится к С-подобным языкам.

Язык поддерживает процедурный стиль программирования, методы и функции.

Поддерживаются структуры, представляющие собой набор элементов разных типов.

## Лексика

### Ключевые слова

| Ключевое слово | Назначение                                           |
|----------------|------------------------------------------------------|
| `int`          | Знаковый целочисленный тип                           |
| `uint`         | Беззнаковый целочисленный тип                        |
| `num`          | Тип для чисел с плавающей точкой                     |
| `char`         | Символьный тип                                       |
| `string`       | Строковый тип                                        |
| `struct`       | Объявление структуры                                 |
| `void`         | Отсутствие возвращаемого значения                    |
| `bool`         | Логический тип                                       |
| `true`         | Значение `Истина` для логического типа               |
| `false`        | Значение `Ложь` для логического типа                 |
| `if`           | Объявление условной конструкции                      |
| `else`         | Объявление альтернативной ветви условной конструкции |
| `while`        | Начало цикла                                         |
| `break`        | Выход из тела цикла                                  |
| `continue`     | Пропуск текущей итерации цикла                       |
| `return`       | Возврат значения из функции                          |

### Идентификаторы

- Идентификатор - последовательность латинских букв любого регистра, десятичных цифр и символов `_`

- Идентификатор не может начинаться с цифры и чувствителен к регистру

### Литералы

#### Целочисленный литерал

- Состоит из одной или более десятичной цифры: `0123456789`

- Разрешены литералы начинающиеся с 0, ведущие 0 не учитываются:  `0012` = `12`

#### Символьные литералы

- Начинается и заканчивается символом одинарной кавычки `'`
- Может содержать только один символ UTF-8 или только одну escape-последовательность

#### Строковые литералы

- Начинается и заканчивается символом двойной кавычки `"`
- Может содержать любое число символов UTF-8 и escape-последовательностей

#### Доступные escape-последовательности

| Последовательность | Значение                  |
|--------------------|---------------------------|
| `\n`               | Перенос строки            |
| `\r`               | Возврат каретки           |
| `\t`               | Табуляция                 |
| `\\`               | Экранирование символа `\` |
| `\'`               | Экранирование символа `'` |
| `\"'`              | Экранирование символа `"` |

### Операторы

| Оператор | Назначение                   |
|----------|------------------------------|
| `+`      | Сложение                     |
| `-`      | Вычитание                    |
| `*`      | Умножение                    |
| `/`      | Деление                      |
| `!`      | Логическое `НЕ`              |
| `&&`     | Логическое `И`               |
| `\|\|`   | Логическое `ИЛИ`             |
| `=`      | Присвоить значение           |
| `==`     | Сравнение "равно"            |
| `!=`     | Сравнение "не равно"         |
| `<`      | Сравнение "меньше"`          |
| `>`      | Сравнение "больше"           |
| `<=`     | Сравнение "меньше или равно" |
| `>=`     | Сравнение "больше или равно" |
| `.`      | Доступ к полю структуры      |

### Скобки и разделители

| Лексема  | Назначение                                          |
|----------|-----------------------------------------------------|
| `;`      | Разделяет инструкции                                |
| `,`      | Разделяет параметры функции                         |
| `(`, `)` | Объявление или вызов функции                        |
| `[`, `]` | Объявление массива или доступ к элементу по индексу |
| `{`, `}` | Блок инструкций, объявление структуры               |

### Комментарии

- Доступны однострочные комментарии
- Комментарий начинается с `//` и продолжается до конца строки
