# Язык SimpleSharp

## О языке

SimpleSharp - строго типизированный императивный язык программирования.

Точкой входа в программу является функция `main`. Язык относится к С-подобным языкам.

В следующих итерациях планируется поддержка процедурного стиля программирования, в частности, поддержка пользовательских
методов и функций.

Планируется поддержка структур, представляющих собой набор элементов разных типов.

## Лексика

### Ключевые слова

Ключевые слова чувствительны к регистру

В разделе описаны все планируемые ключевые слова языка, в том числе те, что будут использоваться в следующих итерациях

| Ключевое слово | Назначение                                           |
|----------------|------------------------------------------------------|
| `int`          | Знаковый целочисленный тип                           |
| `char`         | Символьный тип                                       |
| `string`       | Строковый тип                                        |
| `struct`       | Объявление структуры                                 |
| `void`         | Отсутствие возвращаемого значения                    |
| `bool`         | Логический тип                                       |
| `true`         | Значение `Истина` для логического типа               |
| `false`        | Значение `Ложь` для логического типа                 |
| `if`           | Объявление условной конструкции                      |
| `else`         | Объявление альтернативной ветви условной конструкции |
| `while`        | Начало цикла                                         |
| `break`        | Выход из тела цикла                                  |
| `continue`     | Пропуск текущей итерации цикла                       |

### Идентификаторы

- Идентификатор - последовательность латинских букв любого регистра, десятичных цифр и символов `_`

- Идентификатор не может начинаться с цифры и чувствителен к регистру

- Идентификатор `Write` является зарезервированным именем языка

### Литералы

#### Целочисленный литерал

- Состоит из одной или более десятичной цифры: `0123456789`
- Разрешены литералы начинающиеся с 0, ведущие 0 не учитываются:  `0012` = `12`
- Унарный минус не является частью литерала, диапазон допустимых значений: `0 - 2147483647`

#### Символьные литералы

- Начинается и заканчивается символом одинарной кавычки `'`
- Должен полностью располагаться на одной строке
- Может содержать только один символ Unicode из диапазона BMP или только одну escape-последовательность

#### Строковые литералы

- Начинается и заканчивается символом двойной кавычки `"`
- Должен полностью располагаться на одной строке
- Может содержать любое число символов Unicode из диапазона BMP и escape-последовательностей

#### Доступные escape-последовательности

| Последовательность | Значение                  |
|--------------------|---------------------------|
| `\n`               | Перенос строки (LF)       |
| `\r`               | Возврат каретки (CR)      |
| `\t`               | Табуляция (HT)            |
| `\\`               | Экранирование символа `\` |
| `\'`               | Экранирование символа `'` |
| `\"`               | Экранирование символа `"` |

### Скобки и разделители

Описаны все планируемые лексемы, полные сценарии использования всех лексем будут реализованы в следующих итерациях

| Лексема  | Назначение                                               |
|----------|----------------------------------------------------------|
| `;`      | Разделяет инструкции                                     |
| `,`      | Разделяет параметры функции                              |
| `(`, `)` | Объявление или вызов функции, изменение порядка действий |
| `[`, `]` | Объявление массива или доступ к элементу по индексу      |
| `{`, `}` | Блок инструкций, объявление структуры                    |

### Комментарии и пробельные символы

Доступны однострочные комментарии

- Комментарий начинается с `//` и продолжается до конца строки
- Все символы внутри комментария игнорируются

Пробельные символы служат для разделения лексем и игнорируются

- Перенос строки LF
- Возврат каретки CR
- Пробел SP
- Горизонтальная табуляция HT

Поддерживается подсчёт строк и колонок для определения места лексемы в исходном тексте

Как перенос строки воспринимаются символы:

- Перенос строки LF
- Возврат каретки CR
- Последовательность CR + LF воспринимается как один перенос, а не два

## Синтаксис

### Синтаксис в нотации EBNF

Описывает часть языка, реализованную в текущей итерации

```ebnf
program = "void", "main", "(", ")", block ;
block = "{", { statement },  "}" ;
statement = block | empty_statement | function_call ;

empty_statement = ";" ;
function_call = write_call ;
write_call = "Write", "(", expression, ")", ";" ;

expression = additive_expression ;
additive_expression = multiplicative_expression, { ( "+" | "-" ), multiplicative_expression } ;
multiplicative_expression = exponentiation_expression, { ( "*" | "/" | "%" ), exponentiation_expression } ;
exponentiation_expression = unary_expression, { "^", unary_expression } ;
unary_expression = "-", unary_expression | primary_expression ;
primary_expression = int_literal | "(", expression, ")" ;
```

### Приоритет и ассоциативность операций

Описывает операции, реализованные в текущей итерации

| Оператор      | Приоритет     | Ассоциативность |
|---------------|---------------|-----------------|
| `()`          | 1 (Наивысший) | -               |
| Унарный `-`   | 2             | Правая          |
| `^`           | 3             | Левая           |
| `*`, `/`, `%` | 4             | Левая           |
| `+`, `-`      | 5 (Наинизший) | Левая           |
