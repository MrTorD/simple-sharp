# Список тестов для Interpreter

## Программы соответствующие синтаксису и несодержащие ошибок времени выполнения

- [ ] Пустой блок main: `void main() { }`
- [ ] Допустимо любое количество вложенных блоков и пустых инструкций `;`: `void main() { ; {;{;;}} }`
- [ ] Вывод целочисленного литерала: `void main() { Write(5); }`
- [ ] Вычисление выражения: `void main() { Write(3 + -2); }`
- [ ] Приоритет операций: `void main() { Write(1 + 4 * 2 ^ 3); }`
- [ ] Ассоциативность операций: `void main() { Write( (8 / 4 / 2) ^ 2 ^ 2); }`
- [ ] Изменение порядка операций при помощи скобок: `void main() { Write( (11 + -(4 % 3)) / 3 ); }`

## Программы несоответствующие синтаксису

- [ ] Отсутствие точки входа: `Write(5); `
- [ ] Неверно определена сигнатура метода main: `int main() { Write(5); }`
- [ ] Вызов функции вывода не оканчивается `;`: `void main() { Write(5) }`
- [ ] Отсутствует закрывающая `}` для блока main: `void main() { Write(5); `
- [ ] Выражение должно быть частью вызова функции: `void main() { 5 + 5; } `
- [ ] Некорректное арифметическое выражение: `void main() { Write(5 ++ 4); }`
- [ ] Слишком большой целочисленный литерал: `void main() { Write (2147483648) }`

## Программы содержащие ошибки времени выполнения

- [ ] Целочисленное переполнение сверху: `void main() { Write(2147483647 + 1); }`
- [ ] Целочисленное переполнение снизу: `void main() { Write(-2147483647 - 2); }`
- [ ] Деление на 0: `void main() { Write(5 / 0); }`
