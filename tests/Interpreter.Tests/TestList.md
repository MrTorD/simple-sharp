# Список тестов для Interpreter

## Программы соответствующие синтаксису и несодержащие ошибок времени выполнения

- [x] Пустой блок main: `void main() { }`
- [x] Допустимо любое количество вложенных блоков и пустых инструкций `;`: `void main() { ; {;{;;}} }`
- [x] Вывод целочисленного литерала: `void main() { Write(5); }`
- [x] Несколько вызовов Write: `void main() { Write(1); Write(2); }`
- [x] Вычисление выражения: `void main() { Write(3 + -2); }`
- [x] Приоритет операций: `void main() { Write(1 + 4 * 2 ^ 3); }`
- [x] Ассоциативность операций: `void main() { Write( (8 / 4 / 2) ^ 2 ^ 2); }`
- [x] Изменение порядка операций при помощи скобок: `void main() { Write( (11 - -(4 % 3)) / 3 ); }`

## Программы несоответствующие синтаксису

- [x] Отсутствие точки входа: `Write(5); `
- [x] Неверно определена сигнатура метода main: `int main() { Write(5); }`
- [x] Вызов функции вывода не оканчивается `;`: `void main() { Write(5) }`
- [x] Отсутствует закрывающая `}` для блока main: `void main() { Write(5); `
- [x] Выражение должно быть частью вызова функции: `void main() { 5 + 5; } `
- [x] Некорректное арифметическое выражение: `void main() { Write(5 ++ 4); }`
- [x] Слишком большой целочисленный литерал: `void main() { Write (2147483648) }`

## Программы содержащие ошибки времени выполнения

- [x] Целочисленное переполнение при сложении: `void main() { Write(2147483647 + 1); }`
- [x] Целочисленное переполнение при вычитании: `void main() { Write(-2147483647 - 2); }`
- [x] Целочисленное переполнение при умножении: `void main() { Write(1000000 * 3000); }`
- [x] Целочисленное переполнение при возведении в степень: `void main() { Write(10 ^ 10); }`
- [x] Деление на 0: `void main() { Write(5 / 0); }`
