# Список тестов для Lexer

## Идентификаторы и ключевые слова
- [x] Ключевые слова типов: `int bool string char uint struct void`
- [x] Ключевые слова значений логического типа: `true false`
- [x] Ключевые слова условий, циклов, возврата: `if else while break continue return`
- [x] Разбор идентификаторов: `hello h42 ab_44`
- [x] Ключевые слова в ином регистре считаются идентификаторами: `IF stRing`
- [x] Идентификатор может начинаться и содержать `_`: `_private_Field`

## Литералы
### Целочисленные
- [x] Целочисленные литералы: `12 0 0011`
- [x] Знаки `-` и `+` считаются операторами, а не частью литерала `+44 -77`

### Символьные
- [x] Символьные литералы содержат один символ, ESCAPE-последовательность или экранированный символ: `'c', '\t', '\''`
- [x] Символьные литералы должны открываться и закрываться при помощи `'`: `'a`
- [x] Символьные литералы не содержат 0 или несколько символов: `'', 'ab'`
- [x] Символьные литералы не содержат более одной ESCAPE-последовательности: `'\r\n', '\'\'`
- [x] Символьные литералы не содержат неизвестных ESCAPE-последовательностей: `'\g'`
- [x] Символьные литералы могут содержать символы из UTF-8: `'я'`

### Строковые
- [x] Строковые литералы содержат любое число символов: `"", "a", "Hello, World!"`
- [x] Строковые литералы могут содержать символы из UTF-8: `"Привет, мир!"`
- [x] Строковые литералы могут содержать ESCAPE-последовательности или экранированные символы: `"Hello, \"User\"", "Bye!\n"`
- [x] Строковые литералы должны открываться и закрываться при помощи `"`: `"Hello`
- [x] Строковые литералы не содержат неизвестных ESCAPE-последовательностей: `'"\p"'`

## Пробельные символы и комментарии
- [x] Пропуск пробельных символов: `' ', '\t', '\r', '\n'`
- [x] Пропуск однострочных комментариев: `// Hello, World!`

## Операторы, разделители и скобки
- [x] `x + y - a * b / 4` - Арифметические операторы `+, -, *, /`
- [x] `x > 4 && y < 7 || a == b || c != b` - Строгие операторы сравнения `>, <, ==, !=` и логические операторы `&&, ||`
- [x] `!(x >= y) || b <= 2` - Нестрогие операторы сравнения `>=, <=` и оператор `!`
- [x] `if (arr[5] < 2){}` - Круглые, квадратные, фигурные скобки `(, [, ], ), {, }`
- [x] `point.x = 7;` - Оператор присваивания `=`, оператор точка `.`
- [x] `foo(5, 4);` - Разделитель `;`, разделитель `,`
